# Kenny Inggs

Grower of beards, builder of systems. Cofounder and CTO of Inves Technology.

At Inves Technology, we build and operate [ZARP Stablecoin](https://www.zarpstablecoin.com/), a South African rand stablecoin. Slowly moving the world’s financial systems closer to open, distributed, permissionless and transparent systems.

Strong preference for the fully open kind of open source. The good stuff is the kind you can take apart, build yourself, change and share.

## Sidequests

- **[Pocket Instruments](https://github.com/kinggs/pocket-instruments)** started with a question. What if you could patch every voice of a pocket drum machine into a modular synth? Rhythm runs in a browser and in VCV Rack, both from one Rust engine. [Play Rhythm](https://kinggs.github.io/pocket-instruments/web/rhythm.html).
- **[Scarlett TUI](https://github.com/kinggs/scarlett-tui)** is a Linux terminal mixer for the Focusrite Scarlett 4i4. Built for chasing down questions like “where did the left channel go?”
- **[Sidequests](https://kinggs.github.io/sidequests/)** is where the smaller experiments live, from scoring a game to editing photos.

Found a bug in Rhythm, or have an idea for a patch? [Open an issue](https://github.com/kinggs/pocket-instruments/issues).
